    How does this work?

    Similar details compares the specific words in each film's title, tagline, plot summary and genres (TF-IDF). Similar feel compares overall meaning using pretrained GloVe word vectors, averaged across each film's words. Both were evaluated on held-out TMDB keywords; Similar details scored higher, so it's the default.
